Rotta world sailing chart, 16384 x 16384 Mercator.
Natural Earth 1:10m land geographic data are public domain.
https://www.naturalearthdata.com/about/terms-of-use/
Relief and bathymetry use NOAA NCEI ETOPO1 bedrock global relief.
https://www.ncei.noaa.gov/products/etopo-global-relief-model
https://gis.ngdc.noaa.gov/arcgis/rest/services/DEM_mosaics/ETOPO1_bedrock/ImageServer

Rotta derives the shared water/collision raster, navigable port approaches,
coarse graph, hillshading, textures and bounded tile pyramid from these sources.
Real straits are widened for world-chart sailing. Suez and Panama remain land.
Original elevation exports are not included in the runtime package.
Rebuild tool: tools/world/build_world.py in the private development repository.
